💧 Daily Water Intake Calculator

Get a starting daily-water estimate from weight, activity, and climate.

Method: 33 ml per kg, with fixed additions for activity and hot weather.

Limits: Educational estimate only; it does not account for individual health conditions or medication.

Optional next step: WaterWise for day-to-day logging →

❤️‍🩹 Blood Pressure Category Checker

See which published AHA category a pair of blood-pressure numbers falls into.

Method: Compares systolic and diastolic values against AHA cut-offs; the higher category wins.

Limits: Reference only, not a diagnosis, interpretation, or medical advice.

Optional next step: BP Log for an ongoing record →

📝 Journaling Prompt Generator

Start writing with one prompt when a blank page feels like too much.

Method: Selects one question from a fixed, hand-written prompt set.

Limits: It does not save writing, learn about you, or create a programme.

Optional next step: Zolio for private journal entries →

🔊 Free White Noise Player

Play white, pink, or brown noise with a volume control and sleep timer.

Method: Generates sound in the browser with the Web Audio API.

Limits: No sound library or offline app controls; playback ends when the tab closes.

Optional next step: Hushly for dedicated sleep sounds →

Before you use one

Instant and free: no account, trial, or payment is needed to use these four browser tools.

Your task inputs stay in the page: the calculator and checker work in browser JavaScript; the prompt tool has nowhere to enter an answer; and the player generates audio in the browser. They do not create a saved task history.

Know the boundary: health-related outputs are educational references, not personal medical guidance. The tool page explains its specific method and limit before you use it.
