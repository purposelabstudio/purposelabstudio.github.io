# PurposeLab Studio website

Static source for [purposelabstudio.com](https://purposelabstudio.com): product pages, articles,
free browser tools, and trackable app-store redirects. GitHub Pages serves the repository root
directly; there is no framework build or generated `dist/` deployment.

## Local setup and checks

On a new laptop:

```sh
git clone <repository-url>
cd purposelabstudio-github-io
npm ci
npx playwright install chromium
npm test
```

Serve the root with any static server when reviewing pages, for example:

```sh
python3 -m http.server 4173
# open http://localhost:4173
```

Useful focused commands:

```sh
npm run test:accessibility       # rendered semantics, labels, alt text, keyboard + contrast
node scripts/test-site.mjs       # site structure and content invariants
node scripts/test-tools.mjs      # browser-tool calculations
node scripts/test-links.mjs      # generated /go/ redirect contract
node scripts/audit.mjs --all     # advisory SEO/content audit
npm run build:links              # regenerate /go/ and docs/link-registry.md
```

## What is source and what is generated

Human-owned public content includes the root pages, `about/`, `apps/`, `blog/`, app directories,
`tools/`, `assets/`, `style.css`, `robots.txt`, `sitemap.xml`, and `llms.txt`.

`go/` and `docs/link-registry.md` are generated by `tools/build-links.mjs`; edit
`tools/link-config.json` and regenerate instead of editing those outputs. `dist/`, `node_modules/`,
`.purposelab/`, and PDF render artefacts are local/generated and are not published intentionally.
The planning records under `docs/superpowers/` are historical context, not current site source.

## Optional PurposeLab connection

The repository works standalone with Node.js and Playwright. If the sibling PurposeLab foundation
is available, its `pl` CLI adds routing and safety checks without copying platform code here.
The committed `.vscode/mcp.template.json` and `.gemini/settings.template.json` remain core-only;
active client files are machine-local and ignored.

```sh
export PURPOSELAB_HOME=../purposelab
"$PURPOSELAB_HOME/pl" doctor
"$PURPOSELAB_HOME/pl" enable website-maintenance
"$PURPOSELAB_HOME/pl" render-adapters --write
"$PURPOSELAB_HOME/pl" activate github-copilot
"$PURPOSELAB_HOME/pl" activate gemini-cli
"$PURPOSELAB_HOME/pl" activate github-copilot --check
"$PURPOSELAB_HOME/pl" activate gemini-cli --check
```

`render-adapters --write` previews the enabled profile under `.purposelab/generated/`; `activate`
writes the verified projections to ignored `.vscode/mcp.json` and `.gemini/settings.json`.
GitHub Copilot and Gemini CLI have verified native activation. Claude Code, Codex, Cursor, and
Antigravity are explicit fallbacks that use their committed instruction entrypoint plus
`AGENTS.md` and `pl`; generic agents use the neutral `AGENTS.md` contract.

After activation, run:

```sh
"$PURPOSELAB_HOME/pl" guard
"$PURPOSELAB_HOME/pl" dry-run "website maintenance"
"$PURPOSELAB_HOME/pl" smoke
"$PURPOSELAB_HOME/pl" accessibility
"$PURPOSELAB_HOME/pl" certify
```

For a non-sibling checkout, point `PURPOSELAB_HOME` at the central repository or run
`/path/to/purposelab/pl connect /path/to/purposelab`.

## Publishing guardrails

- Local tests, audits, and generated-file checks are safe; do not submit forms or call publishing,
  cache-purge, analytics, IndexNow, store, or deployment endpoints during validation.
- Treat edits to health/legal claims, privacy text, analytics, canonical URLs, `CNAME`, workflows,
  and store redirects as high consequence and require human review.
- Pushing to `main` can publish through GitHub Pages and trigger IndexNow/cache workflows. Never
  push, deploy, or invoke those workflows without explicit approval.
- Never commit credentials. Repository secrets used by workflows stay in GitHub settings.
